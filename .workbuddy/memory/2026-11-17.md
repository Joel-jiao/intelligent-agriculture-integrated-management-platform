# 2026-11-17

## 数据来源改造：前端不再内置任何业务数据，全部改由后端接口读取
- 用户反馈：未启动后端时页面依然能显示数据。根因是 57 个页面直接 `import` 自 `src/data/mock.ts`（前端打包了全套假数据）。
- 新增数据访问层 `src/api/`：
  - `http.ts`：`fetch` 封装（基址 `VITE_API_BASE_URL`，默认 `/api/v1`，8s 超时，`ApiError` 区分网络失败/超时/HTTP 错误），不做任何本地兜底。
  - `endpoints.ts`：`ENDPOINTS`（24 个集合）、`AGGREGATE_ENDPOINTS`（9 个聚合对象）、`DETAIL_ENDPOINTS`（13 个页面级明细）、类型化 fetcher 与 CRUD helper。
  - `store.ts`：`backend` 状态机（idle/loading/ready/error）+ 响应式容器。启动时 `loadAllData()` 并发拉全部接口，用 `fillArray`/`fillObject` **就地填充**以保持导出引用稳定，页面因此可以维持同步写法。
- 准入层：`App.vue` 仅在 `backend.status === 'ready'` 时渲染 `RouterView`，否则渲染新增的 `components/ui/BackendGate.vue`（加载中 / 后端不可用 + 重试 + `npm run dev:api` 提示）。后端不可用时 `clearAll()` 清空所有容器，**不会回退到假数据**。
- 页面改造：57 处 `@/data/mock` → `@/api/store`；删除 `src/data/mock.ts`（仅保留 `src/data/types.ts`，并补充 ParkInfo/WeatherInfo/SysInfo/QualityOverview/TraceDetail/ScreenConfig/EnvSeries/WaterElectric/MonthlyReportRow/PesticideLedgerRow/DictType 等接口类型）。
- 页面级内联明细数据也搬到后端（db.json + routes.json + DETAIL_ENDPOINTS + store 容器 + 页面 `cloneRows`）：联动策略/执行日志、控制日志、设备操作记录、工单打卡、导出记录、录像回放、API 密钥、会话设备、服务健康、登录设备、灌溉墒情与今日统计。
- 顺带修正：数据字典页 6 类 30 条字典改为 `/api/v1/system/dicts`；农户/操作人下拉改为从 `users` 派生（db.json 补 U-008 周涛）；监管报表辖区下拉改为 `tenants` 派生；大屏默认范围改 `plots` 派生；移动端问候语改用登录态姓名；H5 溯源页脚用 `park.name`，并修掉深色主题遗留的 `rgba(200,240,215,.62)` 低对比文字。
- 后端补充：`routes.json` 新增 `/trace/timeline`、`/trace/detail`、`/system/dicts` 及 13 条明细路由；`db.json` 45+2 个顶层键。`vite.config.ts` 增加 `preview.proxy` 让 `npm run preview` 同样能连后端。`env.d.ts` 声明 `VITE_API_BASE_URL`。
- 验证：`npm run type-check`、`npm run build` 通过；34+13 个接口经 Vite 代理全部 200；headless Chrome 截图确认看板/GIS/联动策略/报表/视频/工单/字典/灌溉/大屏/移动端均渲染后端数据；停掉后端后确认只显示「后端服务不可用」准入页。
- 仍为前端常量的内容（后续可按需接入数据字典）：状态下拉等枚举选项、大屏聚焦项、快捷入口/导航配置、联动策略「场景模板」、RBAC 权限模块树。
